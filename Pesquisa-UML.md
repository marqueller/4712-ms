1-O que é um UML?
UML, ou Unified Modeling Language, é uma linguagem de modelagem usada para especificar, visualizar, construir e documentar sistemas de software. Ela ajuda desenvolvedores e arquitetos de software a criar uma representação gráfica dos componentes e das interações de um sistema.

4- Sobre o Git hub pesquise sistemas concorrentes listando ao menos uma diferença.
 GitLab

Diferença Principal: Integração Contínua e Entrega Contínua (CI/CD). GitLab oferece uma solução integrada para CI/CD diretamente na plataforma, permitindo que você configure pipelines de integração contínua e entrega contínua sem precisar de ferramentas externas. GitHub também possui CI/CD através do GitHub Actions, mas GitLab é frequentemente elogiado por sua abordagem mais unificada e configurável de CI/CD.
2. Bitbucket
Diferença Principal: Suporte a Repositórios Privados Gratuitos. Bitbucket oferece repositórios privados gratuitos para equipes de até 5 usuários, enquanto o GitHub oferece repositórios privados gratuitos, mas com algumas limitações em relação ao número de colaboradores e funcionalidades adicionais em comparação com seus planos pagos.

3. SourceForge
Diferença Principal: Foco em Projetos de Código Aberto e Comunidade. SourceForge é conhecido por ser uma das primeiras plataformas para hospedar projetos de código aberto e tem uma forte ênfase em recursos comunitários e de colaboração, como fóruns e páginas de projeto detalhadas. GitHub também suporta projetos de código aberto, mas SourceForge tem uma abordagem mais antiga e voltada para a comunidade.

4. Azure DevOps
Diferença Principal: Integração Profunda com o Microsoft Azure. Azure DevOps oferece uma integração mais estreita com os serviços do Microsoft Azure, além de uma suite completa de ferramentas para desenvolvimento, testes, e gerenciamento de projetos. GitHub, enquanto oferece integração com Azure, é mais agnóstico e não está tão profundamente integrado com a plataforma Azure quanto o Azure DevOps.

5. Gitea
Diferença Principal: Leveza e Autohospedagem. Gitea é uma plataforma de controle de versão Git autohospedada que é conhecida por sua leveza e simplicidade em comparação com GitHub. É uma solução ideal para quem deseja hospedar seu próprio servidor Git com menos sobrecarga de recursos e configuração, enquanto o GitHub é um serviço baseado em nuvem que não requer instalação ou manutenção por parte do usuário.

6. Phabricator
Diferença Principal: Conjunto Abrangente de Ferramentas de Revisão de Código e Gerenciamento de Projeto. Phabricator oferece uma gama completa de ferramentas para revisão de código, gerenciamento de tarefas e outros aspectos do desenvolvimento de software. Embora GitHub tenha funcionalidades de revisão de código e gerenciamento de projetos, Phabricator é uma plataforma mais completa e integrada para esses processos.
