⭐O que é UML: 
A Unified Modeling Language, ou Linguagem Unificada de Modelagem 
É uma linguagem-padrão (uma linguagem de notação (um jeito de escrever, ilustrar, comunicar)) para modelar e documentar as diversas fases do desenvolvimento de sistemas orientados a objetos.

Os diagramas UML servem para representar visualmente um sistema com seus principais atores, papéis, ações, artefatos ou classes, a fim de melhor compreender, alterar, manter ou documentar informações sobre o sistema.

⭐Tipos de uml: 
- Classe
- Atividade
- Objeto
- Caso de uso
- Sequência

Existem diversos tipos de diagramas UML, cada um com sua própria finalidade e símbolos específicos.

⭐O diagrama de classes 
É um processo de engenharia de software e serve de base para outros diagramas. Isso porque ele é utilizado para mapear o sistema por meio da modelagem dos seus métodos, atributos e classes — além dos relacionamentos definidos entre elas, como herança, composição, associação e dependência.

Tendo isso em mente, um exemplo do dia a dia seria:
Você comprar um produto
A classe se chamaria "classe produto". 
Ela pode ter atributos como "modelo", "marca", "cor", etc.
Os métodos podem ser "encomendar", "pagar",  "receber"...
